# SmartAuth – Android Authentication Application

## Project Overview
SmartAuth is a simple Android application developed using Java and XML layouts. It demonstrates a basic authentication flow with login, registration, password recovery, and password reset screens.

## Features
- Splash screen with application name and logo
- Login screen with input validation
- Registration form with password confirmation
- Forgot Password and Reset Password screens
- Dashboard with a two-column grid of modules
- Profile screen displaying user information
- Logout functionality
- Shared string and color resources
- Alternative colors for night mode
- LinearLayout, GridLayout, and ConstraintLayout usage
- Explicit Intents for screen navigation

## Technologies Used
- Android Studio
- Java
- XML
- Android SDK

## Important Note
This project uses simulated authentication and password recovery. It does not connect to a backend server, send real recovery emails, or persist registered accounts.

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Connect an Android device or start an emulator.
5. Click Run to launch the application.

## Project Purpose
This project demonstrates Android UI design, input validation, resource management, and navigation between activities using Java and XML.
